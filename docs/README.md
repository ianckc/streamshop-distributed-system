# StreamShop Docs

Documentation site for the [StreamShop distributed systems showcase](https://github.com/ianckc/distributed-systems).

## Development

```bash
npm install
npm start
```

Opens at [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm run serve
```

## Structure

| Path | Contents |
|------|----------|
| `docs/intro.mdx` | Project introduction |
| `docs/getting-started/` | Quick start guide |
| `docs/architecture/` | Component documentation |
| `docs/data-flows/` | End-to-end sequence diagrams |
| `docs/adr/` | Architecture Decision Records |
| `docs/runbooks/` | Operational runbooks |
| `docs/development/` | Local dev guide |
