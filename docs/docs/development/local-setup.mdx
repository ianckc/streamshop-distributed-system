# Local Development

## Prerequisites

| Service | Runtime | Status |
|---------|---------|--------|
| `order-api` | Go 1.26+ | **Built** |
| `catalog-api` | Node.js 22 + TypeScript | **Built** (health + Mongo list/detail) |
| `analytics-api` | Python 3.12 | Planned |
| `event-processor` | Rust stable | Planned |

## order-api (implemented)

### With Docker Compose

From the repo root — starts Traefik, Postgres, Mongo, order-api, and catalog-api:

```bash
docker compose up --build
```

### App locally, Postgres in Docker

```bash
docker compose up -d postgres
cd services/order-api
cp .env.example .env
go run ./cmd/server
```

`DATABASE_URL` in `.env.example` points at `localhost:5432`.

### Tests

```bash
cd services/order-api
go test ./...
go test -coverprofile=coverage.out -coverpkg=./... ./...
go tool cover -html=coverage.out -o coverage.html
```

See [order-api](../services/order-api) for endpoints and configuration.

## catalog-api (implemented)

### With Docker Compose

Included in `docker compose up --build`. Health: `http://localhost:3001/health`. Products: `http://localhost:8080/api/catalog/products` and `http://localhost:8080/api/catalog/products/prod-001`.

### App locally, Mongo in Docker

```bash
docker compose up -d mongo
cd services/catalog-api
cp .env.example .env
npm install
npm start
```

`MONGODB_URI` in `.env.example` points at `localhost:27017`.

### Tests

```bash
cd services/catalog-api
npm test
```

See [catalog-api](../services/catalog-api) for endpoints and configuration.

## Environment variables (order-api)

```bash
PORT=3002
SERVICE_NAME=order-api
DATABASE_URL=postgres://streamshop:streamshop@localhost:5432/streamshop?sslmode=disable
```

Copy from `services/order-api/.env.example`. `DATABASE_URL` is **required**.

Future variables (not used yet): `KAFKA_BROKERS`, `REDIS_URL`, `OTEL_EXPORTER_OTLP_ENDPOINT`.

## Environment variables (catalog-api)

```bash
PORT=3001
SERVICE_NAME=catalog-api
MONGODB_URI=mongodb://localhost:27017/streamshop
```

Copy from `services/catalog-api/.env.example`. `MONGODB_URI` is **required**.
