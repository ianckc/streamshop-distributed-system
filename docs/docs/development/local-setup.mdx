# Local Development

## Prerequisites

| Service | Runtime | Status |
|---------|---------|--------|
| `order-api` | Go 1.26+ | **Built** |
| `catalog-api` | Node.js 22 + TypeScript | **Built** (health + Mongo list/detail) |
| `analytics-api` | Python 3.12 | **Built** (ClickHouse summary + Postgres detail) |
| `event-processor` | Rust stable | **Built** (consume `order.created`) |

## order-api (implemented)

### With Docker Compose

From the repo root — starts Traefik, nginx, Postgres, Mongo, Redis, Redis Insight, MinIO, Redpanda, Redpanda Console, ClickHouse, event-processor, analytics-api, order-api, and two catalog-api replicas:

```bash
docker compose up --build
```

### App locally, Postgres in Docker

```bash
docker compose up -d postgres redpanda
cd services/order-api
cp .env.example .env
go run ./cmd/server
```

`DATABASE_URL` in `.env.example` points at `localhost:5432`. `KAFKA_BROKERS` points at `localhost:19092`.

### Tests

```bash
cd services/order-api
go test ./...
go test -coverprofile=coverage.out -coverpkg=./... ./...
go tool cover -html=coverage.out -o coverage.html
```

See [order-api](../services/order-api) for endpoints and configuration.

## catalog-api (implemented)

### With Docker Compose

Included in `docker compose up --build`. Replica 1: `http://localhost:3001/health`. Replica 2: `http://localhost:3011/health`. Products via Traefik → nginx: `http://localhost:8080/api/catalog/products`.

### App locally, Mongo and Redis in Docker

```bash
docker compose up -d mongo redis
cd services/catalog-api
cp .env.example .env
npm install
npm start
```

`MONGODB_URI` and `REDIS_URL` in `.env.example` point at `localhost`.

### Tests

```bash
cd services/catalog-api
npm test
npm run test:coverage
npm run lint
```

See [catalog-api](../services/catalog-api) for endpoints and configuration.

## event-processor (implemented)

Included in `docker compose up --build`. Health/ready: `http://localhost:3004/health` and `http://localhost:3004/ready`.

Unit tests do not need cmake, Kafka, or ClickHouse:

```bash
cd services/event-processor
cargo test
cargo fmt --check
```

See [event-processor](../services/event-processor).

## Environment variables (order-api)

```bash
PORT=3002
SERVICE_NAME=order-api
DATABASE_URL=postgres://streamshop:streamshop@localhost:5432/streamshop?sslmode=disable
KAFKA_BROKERS=localhost:19092
```

Copy from `services/order-api/.env.example`. `DATABASE_URL` and `KAFKA_BROKERS` are **required**.

Future variables (not used yet): `REDIS_URL`, `OTEL_EXPORTER_OTLP_ENDPOINT`.

## Environment variables (catalog-api)

```bash
PORT=3001
SERVICE_NAME=catalog-api
MONGODB_URI=mongodb://localhost:27017/streamshop
REDIS_URL=redis://localhost:6379
S3_ENDPOINT=http://localhost:9000
S3_PUBLIC_ENDPOINT=http://localhost:9000
S3_ACCESS_KEY=streamshop
S3_SECRET_KEY=streamshop
S3_BUCKET=product-images
S3_REGION=us-east-1
```

Copy from `services/catalog-api/.env.example`. `MONGODB_URI`, `REDIS_URL`, and `S3_ENDPOINT` / keys / bucket are **required**.

## Other services

Redpanda is in Compose (Kafka API `localhost:19092`). ClickHouse HTTP is `localhost:8123`.

```bash
# Start backing services only
docker compose up -d postgres redis mongo minio redpanda clickhouse

# Run one service natively for fast iteration
cd services/catalog-api && npm start
cd services/order-api && go run ./cmd/server
cd services/analytics-api && pip install ".[dev]" && python -m analytics_api.main
```
