# catalog-api

Node.js HTTP service for the product catalog.

## Status

| Feature | Status |
|---------|--------|
| `GET /health` | Implemented |
| `GET /api/catalog/products` | Implemented (in-memory) |
| Product detail | Planned |
| MongoDB | Planned |
| Redis cache-aside | Planned |
| MinIO image upload | Planned |
| Nginx replicas | Planned |

## Stack

| | |
|--|--|
| Language | Node.js 22 + TypeScript |
| HTTP | Fastify 5 |
| Port | `3001` (default) |

## Run with Docker Compose

From the repository root:

```bash
cp .env.example .env   # optional
docker compose up --build
```

Starts **Traefik**, **postgres**, **order-api**, and **catalog-api**. Health is at `http://localhost:3001/health`. List products through Traefik at `http://localhost:8080/api/catalog/products` (in-memory until Mongo).

## Endpoints

### `GET /health`

Liveness check.

```bash
curl http://localhost:3001/health
```

```json
{"status":"ok","service":"catalog-api"}
```

### `GET /api/catalog/products`

Returns the product catalog. Data is a hardcoded in-memory array until Mongo is added. Amounts are in **pence**.

```bash
curl http://localhost:8080/api/catalog/products
```

```json
{
  "products": [
    {
      "id": "prod-001",
      "name": "StreamShop Mug",
      "price_pence": 1999,
      "attributes": { "colour": "navy", "material": "ceramic" }
    }
  ]
}
```

`id` values match `product_id` on `POST /api/orders` (e.g. `prod-001`). `attributes` is a free-form string map so later Mongo documents can vary by product.

## Configuration

| Variable | Default | Description |
|----------|---------|-------------|
| `PORT` | `3001` | HTTP listen port |
| `SERVICE_NAME` | `catalog-api` | Shown in health response |

```bash
cp .env.example .env
npm install
npm start
```
