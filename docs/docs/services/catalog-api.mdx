# catalog-api

Node.js HTTP service for the product catalog.

## Status

| Feature | Status |
|---------|--------|
| `GET /health` | Implemented |
| Product list/detail | Planned |
| MongoDB | Planned |
| Redis cache-aside | Planned |
| MinIO image upload | Planned |
| Nginx replicas | Planned |

## Stack

| | |
|--|--|
| Language | Node.js 22 + TypeScript |
| HTTP | Fastify 5 |
| Port | `3001` (default) |

## Run with Docker Compose

From the repository root:

```bash
cp .env.example .env   # optional
docker compose up --build
```

Starts **Traefik**, **postgres**, **order-api**, and **catalog-api**. Health is at `http://localhost:3001/health`. Traefik routes `/api/catalog` to this service; product endpoints are not implemented yet.

## Endpoints

### `GET /health`

Liveness check.

```bash
curl http://localhost:3001/health
```

```json
{"status":"ok","service":"catalog-api"}
```

## Configuration

| Variable | Default | Description |
|----------|---------|-------------|
| `PORT` | `3001` | HTTP listen port |
| `SERVICE_NAME` | `catalog-api` | Shown in health response |

## Local development (without running the app in Docker)

```bash
cd services/catalog-api
cp .env.example .env
npm install
npm start
```

## Tests
