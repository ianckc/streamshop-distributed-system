# Quick Start

## Prerequisites

- Docker Desktop or Docker Engine + Compose v2.20+
- Node.js 20+ (only if you want to run the docs site locally)

## What works today

| Component | Status |
|-----------|--------|
| Traefik v3 | `:8080` → `/api/orders`, `/api/catalog`; dashboard `:8081` |
| `order-api` (Go) | `GET /health`, `POST /api/orders` |
| `catalog-api` (Node) | `GET /health`, `GET /api/catalog/products` (in-memory) |
| PostgreSQL 18 | Order persistence |
| Kafka, analytics, observability | Not yet |

## Run the stack

From the repository root:

```bash
cp .env.example .env   # optional — defaults work out of the box
docker compose up --build
```

This starts **Traefik**, **postgres**, **order-api**, and **catalog-api**. Place orders through the gateway on **:8080**; health and debug calls can still hit **:3001** / **:3002** directly.

### Health checks (direct)

```bash
curl http://localhost:3001/health   # catalog-api
curl http://localhost:3002/health   # order-api
```

### Create an order (via Traefik)

```bash
curl -s -X POST http://localhost:8080/api/orders \
  -H 'Content-Type: application/json' \
  -d '{
    "user_id": "660e8400-e29b-41d4-a716-446655440001",
    "items": [{"product_id": "prod-001", "qty": 2, "price_pence": 1999}]
  }'
```

Dashboard: [http://localhost:8081](http://localhost:8081).

See [order-api](../services/order-api) for request fields, errors, and Postgres inspection.

### List products (via Traefik)

```bash
curl http://localhost:8080/api/catalog/products
```

Data is in-memory until Mongo is added. See [catalog-api](../services/catalog-api).

### Stop

```bash
docker compose down
```

To wipe data and re-run init SQL: `docker compose down -v`

## Run the docs site

```bash
cd docs
npm install
npm start
```

Opens at [http://localhost:3000](http://localhost:3000).
