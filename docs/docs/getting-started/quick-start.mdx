# Quick Start

## Prerequisites

- Docker Desktop or Docker Engine + Compose v2.20+
- Node.js 20+ (only if you want to run the docs site locally)

## What works today

| Component | Status |
|-----------|--------|
| Traefik v3 | `:8080` → `/api/orders`, `/api/catalog` (catalog via nginx); dashboard `:8081` |
| nginx | Round-robin to 2× catalog-api |
| `order-api` (Go) | `GET /health`, `GET /ready`, `POST /api/orders` → Postgres + `order.created` |
| `catalog-api` (Node) | 2 replicas; health, ready, product list/detail, MinIO `image_url` |
| PostgreSQL 18 | Order persistence |
| MongoDB 8 | Product catalog |
| Redis 8 | Cache-aside for catalog list/detail (TTL 60s) |
| Redis Insight | Local GUI on `:5540` (not behind Traefik) |
| MinIO | Presigned `image_url` on catalog list/detail |
| Redpanda | Kafka API `:19092`; Console `:8082`; `orders.events` |
| `event-processor` (Rust) | Consume `order.created` → ClickHouse + Postgres `processed` |
| ClickHouse 24 | `order_events` on HTTP `:8123` |
| `analytics-api` (Python) | `GET /api/analytics/orders/summary`, order detail |
| Observability | `--profile observability`: OTel Collector, Jaeger `:16686`, Prometheus `:9090`, Grafana `:3000` |

## Run the stack

From the repository root:

```bash
cp .env.example .env   # optional — defaults work out of the box
docker compose up --build
```

This starts **Traefik**, **nginx**, **postgres**, **mongo**, **redis**, **redisinsight**, **minio**, **redpanda**, **redpanda-console**, **clickhouse**, **event-processor**, **order-api**, **catalog-api-1**, and **catalog-api-2**. Place orders and list products through the gateway on **:8080**; health and debug calls can still hit **:3001** / **:3011** / **:3002** / **:3004** directly. Redis Insight is on **:5540**. MinIO console is on **:9001**. Redpanda Console is on **:8082**. Redpanda Kafka API is on **:19092**. ClickHouse HTTP is on **:8123**.

### Health checks (direct)

```bash
curl http://localhost:3001/health   # catalog-api-1 liveness
curl http://localhost:3001/ready    # catalog-api-1 Mongo ping
curl http://localhost:3011/health   # catalog-api-2 liveness
curl http://localhost:3002/health   # order-api liveness
curl http://localhost:3002/ready    # order-api Postgres ping
curl http://localhost:3004/health   # event-processor liveness
curl http://localhost:3004/ready    # event-processor Postgres + ClickHouse ping
```

### Create an order (via Traefik)

```bash
curl -s -X POST http://localhost:8080/api/orders \
  -H 'Content-Type: application/json' \
  -d '{
    "user_id": "660e8400-e29b-41d4-a716-446655440001",
    "items": [{"product_id": "prod-001", "qty": 2, "price_pence": 1999}]
  }'
```

Dashboard: [http://localhost:8081](http://localhost:8081). After a successful order, open Redpanda Console at [http://localhost:8082](http://localhost:8082) and inspect topic `orders.events`. Postgres `orders.status` becomes `processed`; ClickHouse `order_events` gets a row. See [event-processor](../services/event-processor).

See [order-api](../services/order-api) for request fields, errors, and Postgres inspection.

### List products (via Traefik)

```bash
curl http://localhost:8080/api/catalog/products
```

Data is seeded into MongoDB on first start. See [catalog-api](../services/catalog-api).

### Get one product (via Traefik)

```bash
curl http://localhost:8080/api/catalog/products/prod-001
```

### Stop

```bash
docker compose down
```

To wipe data and re-run Postgres init SQL and Mongo seed: `docker compose down -v`

## Run the docs site

```bash
cd docs
npm install
npm start
```

Opens at [http://localhost:3000](http://localhost:3000).

## Observability stack

```bash
docker compose --profile observability up --build
```

This adds **otel-collector**, **jaeger**, **prometheus**, and **grafana** alongside all core services.

| Tool | URL | Purpose |
|------|-----|---------|
| Jaeger | [http://localhost:16686](http://localhost:16686) | Distributed traces |
| Prometheus | [http://localhost:9090](http://localhost:9090) | Metrics scraping |
| Grafana | [http://localhost:3000](http://localhost:3000) | Dashboards (admin/admin) |

Services export telemetry to the OTel Collector via OTLP (`:4317` gRPC, `:4318` HTTP). The collector forwards traces to Jaeger and exposes a Prometheus scrape endpoint. A pre-built "StreamShop Overview" dashboard is provisioned into Grafana.

Per-service OTel SDK instrumentation is a separate step — the containers are ready to receive data once instrumentation is wired in.
