# Quick Start

## Prerequisites

- Docker Desktop or Docker Engine + Compose v2.20+
- Node.js 20+ (only if you want to run the docs site locally)

## What works today

| Component | Status |
|-----------|--------|
| `order-api` (Go) | `GET /health`, `POST /api/orders` |
| PostgreSQL 18 | Order persistence |
| Traefik, catalog, Kafka, analytics, observability | Not yet |

## Run the stack

From the repository root:

```bash
cp .env.example .env   # optional — defaults work out of the box
docker compose up --build
```

This starts **postgres** and **order-api** on port **3002** (no API gateway yet).

### Health check

```bash
curl http://localhost:3002/health
```

### Create an order

```bash
curl -s -X POST http://localhost:3002/api/orders \
  -H 'Content-Type: application/json' \
  -d '{
    "user_id": "660e8400-e29b-41d4-a716-446655440001",
    "items": [{"product_id": "prod-001", "qty": 2, "price_pence": 1999}]
  }'
```

See [order-api](../services/order-api) for request fields, errors, and Postgres inspection.

### Stop

```bash
docker compose down
```

To wipe data and re-run init SQL: `docker compose down -v`

## Run the docs site

```bash
cd docs
npm install
npm start
```

Opens at [http://localhost:3000](http://localhost:3000).
