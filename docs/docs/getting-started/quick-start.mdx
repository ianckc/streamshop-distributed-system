# Quick Start

StreamShop runs entirely via Docker Compose. Services are being implemented in phases — see the [architecture plan](https://github.com/ianckc/distributed-systems/blob/main/PLAN.md) for the full roadmap.

## Prerequisites

- Docker Desktop or Docker Engine + Compose v2.20+
- 8 GB RAM recommended for the full profile (4 GB for minimal)
- Node.js 20+ (for running this docs site locally)

## Run the docs site

```bash
cd docs
npm install
npm start
```

The site opens at [http://localhost:3000](http://localhost:3000).

## Run the full stack (coming soon)

Once Phase 1 is implemented:

```bash
# From repository root
make up

# Or directly
docker compose up -d
```

The API gateway will be available at `http://localhost:8080`.

### Compose profiles

| Profile | What runs | RAM (approx) |
|---------|-----------|--------------|
| `minimal` | Gateway, catalog (2×), order API, Postgres, Redis | 2–3 GB |
| `full` | All services, databases, Redpanda, MinIO, observability | 6–8 GB |

```bash
docker compose --profile full up -d
```
