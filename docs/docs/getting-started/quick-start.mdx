# Quick Start

## Prerequisites

- Docker Desktop or Docker Engine + Compose v5.4+
- Node.js 24 (only if you want to run the docs site locally)
- Python 3 (used by `make smoke` to parse JSON)

## What works today

| Component | Status |
|-----------|--------|
| Traefik v3 | `:8080` → `/api/orders`, `/api/catalog`, `/api/analytics`, `/docs/`; dashboard `:8081` |
| nginx | Round-robin to 2× catalog-api |
| `order-api` (Go) | `GET /health`, `GET /ready`, `POST /api/orders` → Postgres + `order.created` |
| `catalog-api` (Node) | 2 replicas; health, ready, product list/detail, MinIO `image_url` |
| PostgreSQL 18 | Order persistence |
| MongoDB 8 | Product catalog |
| Redis 8 | Cache-aside for catalog list/detail (TTL 60s) |
| Redis Insight | Local GUI on `:5540` (not behind Traefik) |
| MinIO | Presigned `image_url` on catalog list/detail; sample images via `make seed` |
| Redpanda | Kafka API `:19092`; Console `:8082`; `orders.events` |
| `event-processor` (Rust) | Consume `order.created` → ClickHouse + Postgres `processed` |
| ClickHouse 24 | `order_events` on HTTP `:8123` |
| `analytics-api` (Python) | `GET /api/analytics/orders/summary`, order detail |
| `docs-site` (Docusaurus) | Static docs at `/docs/` via Traefik |
| Makefile | `make up`, `make seed`, `make smoke`, `make logs`, `make down` |
| Observability | `--profile observability`: OTel Collector, Jaeger `:16686`, Prometheus `:9090`, Grafana `:3000` |

## Run the stack

From the repository root:

```bash
cp .env.example .env   # optional — defaults work out of the box
make up && make seed && make smoke
```

| Target | What it does |
|--------|----------------|
| `make up` | Builds and starts Compose, waits for healthchecks |
| `make seed` | Ensures Kafka topics, upserts sample products, uploads MinIO images, flushes Redis |
| `make smoke` | Lists products, places an order, waits for `processed`, checks analytics |
| `make logs` | Follows Compose logs |
| `make down` | Stops the stack (volumes kept) |

This starts

- **Traefik**
- **nginx**
- **docs-site**
- **postgres**
- **mongo**
- **redis**
- **redisinsight**
- **minio**
- **redpanda**
- **redpanda-console**
- **clickhouse**
- **event-processor**
- **analytics-api**
- **order-api**
- **catalog-api-1**
- **catalog-api-2**

Gateway: **:8080**. Docs: [http://localhost:8080/docs/](http://localhost:8080/docs/). Redis Insight: **:5540**. MinIO console: **:9001**. Redpanda Console: **:8082**. ClickHouse HTTP: **:8123**.

### 30-second walkthrough

1. Browse products: [http://localhost:8080/api/catalog/products](http://localhost:8080/api/catalog/products)
2. Place an order (`make smoke`, or the curl below)
3. Open [Redpanda Console](http://localhost:8082) and inspect topic `orders.events`
4. The processor sets Postgres `orders.status` to `processed` and writes ClickHouse `order_events`
5. Hit [http://localhost:8080/api/analytics/orders/summary](http://localhost:8080/api/analytics/orders/summary)

See [order-api](../services/order-api) and [event-processor](../services/event-processor).

### Manual curls (via Traefik)

```bash
curl http://localhost:8080/api/catalog/products
curl http://localhost:8080/api/catalog/products/prod-001

curl -s -X POST http://localhost:8080/api/orders \
  -H 'Content-Type: application/json' \
  -d '{
    "user_id": "660e8400-e29b-41d4-a716-446655440001",
    "items": [{"product_id": "prod-001", "qty": 2, "price_pence": 1999}]
  }'

curl http://localhost:8080/api/analytics/orders/summary
```

Mongo products also load from `infra/mongo/seed.js` on first start of an empty volume. `make seed` is idempotent if the volume already exists. See [catalog-api](../services/catalog-api).

### Health checks (direct)

```bash
curl http://localhost:3001/health   # catalog-api-1 liveness
curl http://localhost:3001/ready    # catalog-api-1 Mongo ping
curl http://localhost:3011/health   # catalog-api-2 liveness
curl http://localhost:3002/health   # order-api liveness
curl http://localhost:3002/ready    # order-api Postgres ping
curl http://localhost:3004/health   # event-processor liveness
curl http://localhost:3004/ready    # event-processor Postgres + ClickHouse ping
curl http://localhost:3003/health   # analytics-api liveness
curl http://localhost:3003/ready    # analytics-api Postgres + ClickHouse ping
```

Traefik dashboard: [http://localhost:8081](http://localhost:8081).

### Stop

```bash
make down
```

To wipe data and re-run Postgres init SQL and Mongo init seed: `docker compose down -v`, then `make up && make seed`.

## Run the docs site

With Compose (recommended — same URL as in production):

```bash
make up
# http://localhost:8080/docs/
```

For live reload while editing content:

```bash
cd docs
nvm use
npm install
npm start
```

Opens at [http://localhost:3100/docs/](http://localhost:3100/docs/) (not `:3000`, which is Grafana when the observability profile is up).

## Observability stack

```bash
docker compose --profile observability up --build
```

This adds **otel-collector**, **jaeger**, **prometheus**, and **grafana** alongside all core services.

| Tool | URL | Purpose |
|------|-----|---------|
| Jaeger | [http://localhost:16686](http://localhost:16686) | Distributed traces |
| Prometheus | [http://localhost:9090](http://localhost:9090) | Metrics scraping |
| Grafana | [http://localhost:3000](http://localhost:3000) | Dashboards (admin/admin) |

Services export telemetry to the OTel Collector via OTLP (`:4317` gRPC, `:4318` HTTP). The collector forwards traces to Jaeger and exposes a Prometheus scrape endpoint. A pre-built "StreamShop Overview" dashboard is provisioned into Grafana.
